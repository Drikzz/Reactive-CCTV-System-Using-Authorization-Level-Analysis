# Simple Multi-Angle Capture

This project provides a simple solution for capturing images from a webcam at multiple angles to enhance face recognition datasets. It is designed to be user-friendly and does not require any external libraries, making it accessible for anyone to use.

## Purpose

The primary goal of this project is to facilitate the collection of face images from various angles, which can improve the performance of face recognition systems. By capturing images from different perspectives, users can create more robust datasets for training machine learning models.

## Features

- Capture images from a webcam at predefined angles.
- Simple and intuitive user interface.
- No external dependencies required.
- Easy to follow instructions for capturing images.

## Getting Started

To get started with the simple multi-angle capture, follow these steps:

1. **Clone the Repository**: Download or clone the repository to your local machine.
2. **Navigate to the Project Directory**: Open a terminal and navigate to the project directory.
3. **Run the Capture Script**: Execute the `simple_capture.py` script to start capturing images. You will be prompted to enter your name and follow the on-screen instructions.
4. **Follow the Instructions**: Refer to the `capture_instructions.txt` file for detailed guidance on how to set up your webcam and capture images effectively.

## Dataset Structure

Users are encouraged to organize their captured images in a specific structure to facilitate easy access and processing. Refer to the `datasets/README.md` file for guidelines on how to structure your dataset.

## Example Dataset Structure

For a clear understanding of how to organize your dataset, check the `examples/sample_dataset_structure.txt` file, which outlines the expected folder and file organization.
