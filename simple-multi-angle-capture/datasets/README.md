# Dataset Structure and Submission Guidelines

This README file provides important information regarding the organization and submission of datasets for the Simple Multi-Angle Capture project.

## Dataset Structure

When capturing images, please ensure that your dataset is organized in the following structure:

```
datasets/
└── <your_name>/
    ├── frontal/
    │   ├── <image1>.jpg
    │   ├── <image2>.jpg
    │   └── ...
    ├── left_profile/
    │   ├── <image1>.jpg
    │   ├── <image2>.jpg
    │   └── ...
    ├── right_profile/
    │   ├── <image1>.jpg
    │   ├── <image2>.jpg
    │   └── ...
    ├── quarter_left/
    │   ├── <image1>.jpg
    │   ├── <image2>.jpg
    │   └── ...
    ├── quarter_right/
    │   ├── <image1>.jpg
    │   ├── <image2>.jpg
    │   └── ...
    ├── up/
    │   ├── <image1>.jpg
    │   ├── <image2>.jpg
    │   └── ...
    └── down/
        ├── <image1>.jpg
        ├── <image2>.jpg
        └── ...
```

Replace `<your_name>` with your actual name or identifier. Each angle should have its own folder containing the captured images.

## Submission Guidelines

1. **Image Quality**: Ensure that the images are clear and well-lit. Avoid blurry or dark images as they may affect the recognition accuracy.
   
2. **File Format**: Use JPEG format for the images. Other formats may not be supported.

3. **Naming Convention**: Name your images in a consistent manner, such as `<your_name>_<angle>_<number>.jpg`, to help with organization and identification.

4. **Compression**: If you have a large number of images, consider compressing the dataset into a ZIP file before submission.

5. **Submission Method**: Please send your organized dataset folder or ZIP file to the designated email or upload link provided by the project coordinator.

By following these guidelines, you will help ensure that your dataset is ready for use in the Simple Multi-Angle Capture project. Thank you for your contribution!
